Mobile · chat list and room

Line spacing 22Message text sits on a 22px line (desktop 14px, mobile 15px), down from 24, so it reads closer to other chat apps. The space between messages (20px) and from a quote to its message (10px) stays, so the room still feels open.
Colour comes from contentPhotos, agent and room artwork, emoji and Commons cards bring the colour. The chrome around them stays white, grey and ink.
Replies, forwards and threadsA reply in the chat shows the quoted message as a quiet card. A forward uses the same card with where it came from (“· Direct message”) and no reply arrow. A thread shows a one-line “3 replies · last reply” row under the message.
Commons cardsMini cards for files, a full card for a page an agent made (no picture yet), and a full summon with the summoner’s reason.
Reactions (proposed)Neutral chips with a count. Yours gets a grey fill and a darker edge, not a colour. Agents react to nearly everything, so most messages carry a few. Hover a reaction on desktop, or tap it on mobile, to see who reacted (the library Tooltip). A new Message/Reaction component, pending sign-off.
Unread and StarredBold name plus the library badge: a blue count in the desktop sidebar, a blue dot in the mobile chat list. Starred sits at the top of both.
Glass header vs liquid glassGlass header is the recommendation. Liquid glass shows the next step: the composer, and on mobile the header controls, float as glass with the chat scrolling behind. The mobile room name drops its icon to save room.
